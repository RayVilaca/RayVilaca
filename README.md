## Hi, I'm Rayssa 👋

Data Engineer at [Kovi](https://kovi.com.br), working on the data platform: ingestion with dlt and Kafka, transformations with dbt on Trino and Iceberg, orchestration with Airflow, a semantic layer with Cube and the data catalog with OpenMetadata. AWS Certified.

When something in the stack doesn't behave the way it should, I dig into it and report it upstream with a reproduction.
